Using the tool

(First off: not optimised for mobile; please use a pc)

Enter what classes you have in the table below; you can use the subtitle to put info about teacher, location etc. Changing some values will not do anything because they are set on your timetable (but these will be blank on the printout anyway.) You will need to leave some values blank.

It's recommended to generate the timetable regularly while editing to make sure you aren't inputting incorrectly.

Input not appearing on L6: L3 and L4 seem to be combined in some weird ways so if you've left L3/L4 blank while filling it in and L6 isn't appearing, it may be worth pushing all your inputs back one.
